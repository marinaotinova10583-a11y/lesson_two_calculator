# СемБюджет

Калькулятор семейного бюджета — автономное веб-приложение без серверов и зависимостей. Работает офлайн прямо в браузере.

## Возможности

- Учёт доходов и расходов по категориям
- Автоматический пересчёт итогов и остатка
- Диаграмма структуры расходов
- Сохранение данных в браузере (localStorage)
- Экспорт в CSV (Excel) и печать / PDF
- Светлая и тёмная тема
- Адаптивная вёрстка

## Структура


## Как открыть

1. Откройте `index.html` в браузере — это стартовая страница.
2. Нажмите «Открыть калькулятор» или перейдите к `calculator.html`.

Можно просто дважды кликнуть по файлу — сервер не нужен.

Локальный просмотр с сервером (по желанию):

```bash
npx serve .
```

## Данные

Все введённые суммы хранятся локально в браузере под ключом `semBudgetData`. Тема — в `budgetTheme`. Данные никуда не отправляются.
